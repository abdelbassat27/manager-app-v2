## الجديد في v2
- **حسابات متعددة (مالك / موظف):** أضف موظفين من الإعدادات، كل واحد بحسابه الخاص، بينما البيانات مشتركة. صفحات الإعدادات والنسخ الاحتياطي والبيانات الخطرة محصورة بحساب المالك.
- **فواتير قابلة للطباعة / PDF:** كل عملية بيع (POS) وكل مشروع وكل تقرير مالي يمكن طباعته أو حفظه كـ PDF مباشرة من المتصفح (زر "طباعة").
- **بحث وفلترة وترتيب** في كل الجداول: المنتجات، سجل المبيعات، المواشي، المهام، العمليات المالية، الديون.
- **تنبيهات وتذكيرات:** جرس إشعارات في الأعلى يجمع كل ما يحتاج انتباهاً: نفاذ مخزون، تطعيمات مستحقة/متأخرة، مهام متأخرة، ديون قريبة/متأخرة الاستحقاق.
- **الديون والذمم:** تتبّع ما هو "لنا" وما هو "علينا" مع تاريخ استحقاق وتنبيه تلقائي.
- **تقارير ورسوم بيانية أوسع:** توزيع المصاريف/المداخيل حسب التصنيف (دونات)، اتجاه آخر 6 أشهر، توزيع السلالات في المواشي.
- **سجل مبيعات كامل** لكل عمليات نقطة البيع (POS) مع اسم العميل.
- **تقدّم المهام قابل للتحديث** مباشرة من جدول المهام (شريط تمرير) بدل أن يكون للعرض فقط.
- **ملف تجاري** (اسم المنشأة، الهاتف، العنوان، رمز العملة) يظهر في رأس كل المطبوعات.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (مثلاً `manager-app`)
2. ارفع **محتويات** هذا المجلد إلى الفرع `main` (الملفات في الجذر وليس داخل مجلد فرعي إن أمكن)
3. Settings → Pages → Source: Deploy from branch → `main` / root
4. افتح: `https://USERNAME.github.io/REPO_NAME/`

إذا كان لديك موقع منشور مسبقاً بالنسخة القديمة: استبدل كل الملفات بمحتوى هذا المجلد ثم أعد الرفع (commit/push). بياناتك الحالية (LocalStorage) **لن تُفقد** لأن مفاتيح التخزين نفسها لم تتغيّر — فقط تأكد من رفع نسخة احتياطية (تصدير JSON) قبل أي تحديث كبير مستقبلاً.

البيانات تُحفظ في LocalStorage للمتصفح (على هذا الجهاز/المتصفح فقط). استخدم النسخ الاحتياطي (تصدير/استيراد JSON) بانتظام، وقبل مسح بيانات المتصفح أو تغيير الجهاز.
